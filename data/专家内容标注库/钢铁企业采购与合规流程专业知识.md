## 一、钢材产品与标准体系

### 1.1 主要钢材品类与典型用途

- **长材类**：螺纹钢（钢筋混凝土用热轧带肋钢筋，HRB400/HRB400E 等）、线材（盘条，用于拉丝、建筑）、圆钢、型钢（角钢、槽钢、工字钢、H 型钢）。
- **板带类**：热轧卷板/中厚板（结构、船舶、容器、管线用）、冷轧卷板（家电、汽车、五金）、镀锌板、彩涂板。
- **管材类**：无缝管、焊管（流体管、结构管、石油套管）。
- **特种与不锈钢**：不锈钢热轧/冷轧板（300 系、400 系）、耐候钢、电工钢（硅钢）。

**审查含义**：品类不同，执行标准、计量方式、验收要求差异很大。合同中必须写清具体品类与牌号，笼统写「钢材」无法确定质量基准。

### 1.2 标准体系：强制性标准与推荐性标准

- **GB（强制性国家标准）**：必须执行，不符合不得生产、销售、进口。例如 GB 1499.1-2024、GB 1499.2-2024《钢筋混凝土用钢》（2024 年 9 月 25 日起由 GB/T 转为 GB 强制）。
- **GB/T（推荐性国家标准）**：自愿采用，但**一旦在合同中引用即成为合同义务**。常见：GB/T 700（碳素结构钢）、GB/T 1591（低合金高强度结构钢）、GB/T 3274（热轧厚钢板和钢带）、GB/T 709（尺寸外形重量偏差）、GB/T 2101（型钢验收包装标志）。
- **行业标准（YB/T 等）、企业标准（Q/xxx）**：常见于专用产品，需在合同中明确标准号。

**审查含义**：质量条款应写明「牌号 + 标准号 + 版本年号」；推荐性标准必须写入合同才有约束力；标准换版时要同步更新合同与技术协议。

### 1.3 牌号命名规则（快速识别）

- **碳素结构钢**：Q + 屈服强度值 + 质量等级 + 脱氧方法，如 **Q235B**（屈服强度 235MPa，B 级质量）。
- **低合金高强度钢**：Q + 屈服强度 + 质量等级，如 **Q355B**（原 Q345）。
- **热轧带肋钢筋**：HRB + 屈服强度 + 特性符号，如 **HRB400E**（E = 抗震）。
- **压力容器用钢**：Q345R、Q245R（R = 容器）。
- **锅炉用钢**：Q245**G**、Q345**G**（G = 锅炉）。
- **船用钢**：以船级社规范标识（如 AH36、DH36）。

**审查含义**：牌号后缀字符（E/R/G）承载特定用途要求，缺写或错写会导致用错料；合同中「Q235」与「Q235B」不是同一要求。

## 二、计量与交付

### 2.1 理计与磅计（钢材交易第一争议源）

- **磅计（过磅计重）**：以实际称重为准，常见于板带、型钢、废钢等。
- **理计（理论计重）**：按体积 × 密度计算，螺纹钢、线材等长材普遍采用；国家标准规定理论重量与允许偏差（如螺纹钢按 GB/T 1499 系列规定的理论重量交货）。
- **差异来源**：负偏差轧制、表面处理状态、包装物重量是否计入。

**审查含义**：必须写明计量方式、计量地点（发货地或到货地）、允许偏差（常见 ±3‰～±5‰）及超偏差处理方式；理计交货时约定是否允许负偏差及上限。

### 2.2 交货状态与质量证明书

- **交货状态**：热轧、控轧控冷（TMCP）、正火、调质等，直接影响性能与价格。
- **质量证明书（质保书）**：应载明炉号、批号、化学成分、力学性能、执行标准；**炉批号须与实物标识一致**，是质量追溯的核心凭证。
- **复验**：重要用途钢材（压力容器、船舶、重点工程）通常约定到货复验，费用与不合格处理须明确。

**审查含义**：合同应约定随货提供质保书（原件或加盖质检章复印件）、复验条款、炉批号一致性要求；无质保书或标识不符的应拒收。

### 2.3 交付与风险转移

- 钢材通常约定**交付即风险转移**（发货或到货），但风险转移不等于质量责任转移，质量问题仍可追索。
- 大额交易常见「**所有权保留**」安排（货款付清前所有权不转移），用于控制赊销风险。
- 运输责任（承运人选择、运费承担、在途损耗）须明确，钢铁物流损耗常见于多次倒运与露天堆放。

## 三、采购模式与价格机制

### 3.1 主要采购模式

| 模式 | 特点 | 主要风险 |
| --- | --- | --- |
| 年度长协 | 锁量不锁价或部分锁价，按月/季定价 | 价格机制条款不清、量价不匹配 |
| 现货采购 | 随行就市，交付快 | 价格波动、货源真实性 |
| 期货套期保值 | 用期货对冲现货价格风险 | 越权开展衍生品交易、投机 |
| 招标采购 | 竞争定价，适用于工程项目与大批量 | 规避招标、歧视性条款 |
| 托盘贸易 | 引入资金方垫资 | **易滑向融资性贸易**，国企高风险区 |

### 3.2 价格机制与指数定价

- 钢铁行业普遍采用**指数定价**：以第三方价格指数（如国内钢材价格指数）为基准，加减固定价差，按周/月结算。
- 合同中应明确：指数名称与来源、取值时间点（如「结算月前一自然月平均价」）、发布主体、指数停发时的替代机制。

**审查含义**：只写「随行就市」「按市场价」而无所指指数的，定价条款无法执行，属于重大缺陷。

### 3.3 识别融资性贸易的特征（国企红线）

- 交易的**真实货物需求存疑**：下游为同一实际控制人，或货物仓储不动、仅在账面上「走单」。
- **固定收益**：不论市价如何波动，一方收取固定「资金占用费」或保底利润。
- **闭环循环**：A→B→C→A 的循环购销，或同日同价的对开、对冲。
- **凭证与物流脱节**：有合同有发票，但缺少真实的运输、出入库、检斤记录。
- **主体特征**：参与方多为轻资产贸易公司，无仓储、无加工能力。

**审查含义**：国资委「十不准」明令禁止虚假贸易与融资性贸易。发现上述特征应暂停交易并上报，审查重点在于**真实物流凭证**而非合同文本本身。

## 四、质量异议处理流程

1. **到货初检**：核对质保书、炉批号、标识、外观与数量。
2. **外观与数量异议**：通常在收货后短期限内提出（如 3～7 日），以便现场留证。
3. **内在质量异议**：需取样复验，期限应长于初检（如 15～30 日或至质保期内），实践中常有争议。
4. **复验机构**：优先约定双方认可的第三方检测机构；单方委托的检测结论对方可能不认可。
5. **处理方式**：退货、换货、降价（按不合格品折价）、赔偿（含连带损失如停工损失）。
6. **证据固定**：现场照片、影像、检斤单、封样样品、往来函件；**未在异议期内书面提出异议将丧失索赔权**。

**审查含义**：审核合同质量条款时，重点检查异议期是否合理（不能过短）、隐蔽瑕疵是否例外、复验机制是否可操作。

## 五、仓储物流与货权管理

- **货权凭证**：入库单、仓单、提单、货权转移确认书。仓单应符合《民法典》第九百一十条的形式要求。
- **常见风险**：
  - **仓单重复质押**：同一批货开出多份仓单用于融资（钢贸行业历史高发）。
  - **仓储方资信不足**：小型仓库挪用、串换货物，甚至无实物。
  - **「一货多卖」**：货未实际出库即转手多次。
- **风险控制**：核验仓储方资质与营业执照；实地盘库核对标识与数量；查询仓单是否已质押登记；大额交易采用实物交接、分批付款。
- **运输环节**：关注承运人资质与保险（货运险）、在途损耗约定、装卸责任划分。

**审查含义**：以仓单或货权转移凭证替代实物交付的采购，须把「存货真实性核验」作为审查前置条件。

## 六、招采平台与流程实务

- **常见平台**：钢铁企业多使用自有或第三方电子招投标平台（企业智慧招投标平台、欧冶采购等），实现公告发布、投标、开标、评标线上化。
- **流程节点**：采购需求提报 → 采购方式审批 → 招标文件审核 → 发布公告 → 投标 → 开标评标 → 定标审批 → 合同签订 → 履约与验收 → 结算付款 → 供应商评价。
- **关键控制点**：
  1. 需求与预算是否匹配（避免超预算采购）；
  2. 采购方式选择是否符合门槛规定（规避招标的高发点）；
  3. 招标文件技术参数是否存在品牌指向（排他性条款的高发点）；
  4. 评标委员会构成与评审过程是否合规；
  5. 合同是否背离招标文件实质性内容；
  6. 履约验收是否有第三方参与。
- **电子化留痕**：平台操作日志、IP 记录可作为围标串标线索（如同一 IP 多家报价、报价文件雷同）。

**审查含义**：招标投标环节的问题多在「程序」而非「文本」；审查时应结合平台记录核验程序合规性。

## 七、采购合规风险信号清单（快速筛查）

| 风险信号 | 可能对应的问题 |
| --- | --- |
| 合同未写牌号与标准号 | 质量条款缺失，验收无依据 |
| 计量方式为「按实际重量」 | 磅计/理计不明，结算争议 |
| 定金比例超过 20% | 超部分不产生定金效力 |
| 预付款超过 30% 且无担保 | 资金回收风险 |
| 无明确异议期或异议期过短 | 丧失索赔权 |
| 价格写「随行就市」无指数 | 定价条款不可执行 |
| 付款与验收节点脱节 | 以付款制约质量的能力丧失 |
| 同一实际控制人多方参与 | 融资性贸易 / 围标风险 |
| 有合同发票但无物流凭证 | 虚假贸易 / 空转走单 |
| 供应商资质文件缺失或过期 | 主体资格与产品合法性风险 |
| 合同条款与招标文件不一致 | 背离实质性内容，合同可能无效 |
| 合同无廉洁条款 | 商业贿赂风险敞口 |

## 八、常用术语表

| 术语 | 含义 |
| --- | --- |
| 理计 / 磅计 | 理论计重 / 过磅计重，两种计量结算方式 |
| 负偏差 | 实际重量或尺寸低于标准值的允许范围及实际程度 |
| 炉批号 | 炼钢炉次与轧制批次编号，质量追溯依据 |
| 质保书 | 质量证明书，载明化学成分与力学性能 |
| TMCP | 控轧控冷工艺，常用于高强钢生产 |
| 长协 | 年度长期协议采购，锁量或部分锁价 |
| 托盘 | 由资金方垫资的贸易模式，易演变为融资性贸易 |
| 走单 / 空转 | 无真实货物流动的虚假贸易形态 |
| 十不准 | 国资委规范央企贸易、严禁虚假贸易的禁止性要求 |
| 三同时 | 建设项目安全设施与主体工程同时设计、施工、投产使用 |
