# 采购合同常见问题与风险案例集（钢材及相关产品）

> **文档类型**：典型案例整理集
> **用途**：作为「典型案例库」知识库语料，供合同审查时类比参考
> **内容性质**：整理、改编自公开裁判文书、行业实务与监管通报的常见问题，人物、企业、金额均为示意，非真实案例
> **入库建议**：按一、二级标题分段即可（每个「## 案例」为一个检索单元）

## 案例一：计量方式约定不明引发重量争议

### 常见情形
合同只写「按供货方计量为准」或干脆不写计量方式。钢材交易存在**过磅计重（磅计）**与**理论计重（理计）**两种方式，同一批货两者差值可达 3%～6%。供货方按理计交货、采购方按磅计验收，结算时各执一词。

### 风险后果
重量差额直接变成货款争议；若合同未约定误差范围与结算基准，采购方往往因「已签收」而难以追偿。

### 依据
《民法典》第五百一十条、第五百一十一条（约定不明确时的补充规则）；《计量法》关于计量器具与计量准确度的规定。

### 审查要点
1. 必须明确写「磅计」或「理计」，不能只写「按实际重量结算」；
2. 约定计量器具、计量地点（发货地磅 / 到货地磅）及允许偏差；
3. 约定差异超过约定偏差时的处理方式（复磅、第三方计量、扣款公式）；
4. 约定复磅费用承担方（通常由过错方承担）。

## 案例二：质量标准只写「符合国家标准」，未明确牌号与标准号

### 常见情形
合同质量条款写「质量符合国家有关标准」「按国标供货」，未写明产品牌号、执行标准号及版本年号。供货方以低牌号、旧版本标准的产品交货。

### 风险后果
验收时无法认定违约；即便起诉，因缺乏明确的质量约定，法院可能认定「已符合约定」而驳回赔偿请求。

### 依据
《产品质量法》第二十六条；《标准化法》第二十五条（不符合强制性标准的产品不得销售）；相关强制性国标如 GB 1499.1-2024、GB 1499.2-2024《钢筋混凝土用钢》。

### 审查要点
1. 质量条款必须写全「**牌号 + 执行标准号 + 版本年号**」，例如「HRB400E，符合 GB 1499.2-2024」；
2. 涉及强制性标准的，注明「不低于强制性国标要求」；
3. 若客户有特殊要求（如抗震、耐候、探伤），在合同中单独列明技术条件；
4. 明确质量证明书（质保书）提供义务及随货交付要求。

## 案例三：质量异议期约定过短或缺失，采购方丧失索赔权

### 常见情形
合同未约定检验期间，或约定「收货后 3 日内提出异议，逾期视为合格」。钢材的部分缺陷（如内部裂纹、成分偏差）需复验才能发现，3 日内根本来不及。

### 风险后果
按《民法典》规定，超过约定异议期未提出异议的，视为质量合格；采购方失去索赔与退货权利，损失全部自担。

### 依据
《民法典》第六百二十条、第六百二十一条（检验期间与质量异议）；第六百二十二条（怠于通知视为符合约定）。

### 审查要点
1. 采购方立场应争取较长的异议期，并区分「外观异议」与「内在质量异议」两档期限；
2. 约定「隐蔽瑕疵不受异议期限制」或「质量保证期内均可提出」；
3. 明确复验机构（如双方认可的第三方检测机构）与费用承担；
4. 避免接受「逾期视为合格」的单方表述，或至少争取对隐蔽瑕疵的例外。

## 案例四：定金约定超过合同金额的 20%

### 常见情形
为锁定货源，采购方支付合同金额 30% 甚至 50% 作为「定金」。供货方违约时只愿双倍返还其中 20% 部分。

### 风险后果
超过主合同标的额 20% 的部分不产生定金效力，仅作为预付款处理，无法主张双倍返还，担保效果大打折扣。

### 依据
《民法典》第五百八十六条（定金数额不得超过主合同标的额的 20%，超过部分不产生定金效力）。

### 审查要点
1. 定金比例不得超过合同金额 20%，超出部分应改写为「预付款」并单独约定退还条件；
2. 明确区分「定金」与「订金」「预付款」，措辞直接影响法律效果；
3. 大额采购建议以「预付款 + 银行保函 / 履约保证金」替代高额定金。

## 案例五：预付款比例过高且无担保

### 常见情形
供货方要求支付 50% 以上预付款，合同未约定任何担保措施。付款后供货方经营恶化、停产或失联。

### 风险后果
预付款形成对供货方的无担保债权，破产清算中受偿顺序靠后，回收率极低。

### 依据
《民法典》合同编买卖合同章；《企业破产法》关于债权清偿顺序的规定。

### 审查要点
1. 预付款比例原则上不超过 30%，超出部分要求提供银行保函或第三方担保；
2. 约定预付款与履约进度挂钩（如按分批交货冲抵）；
3. 审查供货方履约能力（产能、在手订单、涉诉与失信信息）；
4. 约定预付款专用、不得挪用的约束条款与违约责任。

## 案例六：验收与付款脱节，未验收即全额付款

### 常见情形
合同约定「货到即付全款」，验收条款形同虚设；或付款节点写成「签订合同后 X 日付款」，与实际交付无关。

### 风险后果
付款后发现问题货物，采购方只能主张违约赔偿，丧失「以付款制约交付质量」的主动权。

### 依据
《民法典》第五百二十六条（先履行抗辩权）、第六百二十六条（买受人付款义务与交付的关系）。

### 审查要点
1. 付款节点必须与交付、验收、开票等实质性节点绑定；
2. 保留质量保证金（通常为合同金额 5%～10%），质保期满后支付；
3. 明确验收标准、验收期限与「验收不合格的付款暂缓」条款；
4. 大额采购宜采用「预付款 + 到货款 + 验收款 + 质保金」结构。

## 案例七：违约金约定畸高或畸低，且未设上限

### 常见情形
合同只写「违约方承担一切损失」，或约定日万分之五但无累计上限；亦有约定过高（如日 1%）导致无法获法院支持的。

### 风险后果
约定畸高会被法院调减（通常以损失的 130% 为限），约定过低则无法覆盖实际损失；无上限条款可能导致赔付金额失控。

### 依据
《民法典》第五百八十五条；《最高人民法院关于适用〈民法典〉合同编通则若干问题的解释》关于违约金调整的规定。

### 审查要点
1. 逾期交货/逾期付款分别约定具体违约金计算方式（如日万分之三至万分之五）；
2. 设定违约金累计上限（如不超过合同金额 20%），避免无限累加；
3. 明确损失赔偿范围（直接损失、可得利益、维权费用的承担）；
4. 避免「承担一切损失」这类无法量化的表述。

## 案例八：赊销钢材未约定所有权保留，货款两空

### 常见情形
对长期合作客户赊销，货已交付但未约定所有权保留。客户将钢材转售或抵押，随后无力付款。

### 风险后果
货物交付即所有权转移，供货方仅剩普通债权；若货物已被转售给善意第三人，无法追回货物。

### 依据
《民法典》第六百四十一条（所有权保留）、第六百四十二条（出卖人取回权）、第六百四十一条关于登记对抗的规定。

### 审查要点
1. 赊销场景应约定所有权保留条款：「货款付清前，标的物所有权归出卖人」；
2. 约定买受人不得处分（转售、抵押）标的物，或处分需经书面同意；
3. 建议办理所有权保留登记，以对抗善意第三人；
4. 约定取回权的行使条件与程序。

## 案例九：仓储环节仓单重复质押，货权不清

### 常见情形
以仓单交付替代实物交付，但仓单来源不清、未核验仓储方资质；同一批货被开出多份仓单重复融资。

### 风险后果
采购方付款后无法提货，或提货时发现货物已因质押被查封，形成「付了钱拿不到货」的局面。钢贸领域历史上发生过多起同类风险事件。

### 依据
《民法典》第九百一十条（仓单）、第九百零四条至第九百一十八条（仓储合同）；《九民纪要》关于仓单质押的裁判规则。

### 审查要点
1. 核验仓储方资质与存货真实性（实地盘库、查询仓储方确认函）；
2. 仓单应载明存货人、货物品名规格、数量、储存地点等法定事项；
3. 核实仓单是否已被质押、是否存在重复开单；
4. 大额交易优先采用「实物交接 + 现场验收」，慎用纯仓单流转。

## 案例十：名为买卖、实为借贷（融资性贸易）

### 常见情形
以采购合同形式向缺乏真实货物交易需求的企业「采购」钢材，实质是提供资金并收取固定收益（如「货款 + 固定资金占用费」），或采用闭环、走单、空转等模式。

### 风险后果
国有企业被明令禁止开展各类虚假贸易与融资性贸易，一旦被认定为融资性贸易，相关合同可能被认定无效，责任人面临追责；同时存在资金无法收回的重大损失风险。

### 依据
国资委《关于规范中央企业贸易管理严禁各类虚假贸易的通知》（国资财评〔2023〕74 号，「十不准」）；《九民纪要》关于「名为买卖实为借贷」的认定规则。

### 审查要点
1. 核查交易是否具有真实货物需求与物流流转（入库单、运输单据、出入库记录）；
2. 警惕「固定收益」「保底利润」「上下游关联循环」等特征；
3. 审查是否存在同日同价的对开、闭环购销；
4. 确认参与方是否为同一实际控制人控制的关联企业。

## 案例十一：供应商不具备法定资质（以钢筋为例）

### 常见情形
采购建筑用钢筋，供应商无工业产品生产许可证；或供应商为贸易商，无法提供生产企业的许可证与质保书。

### 风险后果
产品合法性存疑，工程使用环节可能被主管部门查处；发生质量事故时追责链条断裂，采购方难以免责。

### 依据
《工业产品生产许可证管理条例》；钢筋混凝土用热轧钢筋、冷轧带肋钢筋等产品实行生产许可证管理；GB 1499.2-2024（强制性国标）。

### 审查要点
1. 在供应商准入环节核验生产许可证（产品范围、有效期）；
2. 要求随货提供质量证明书，并核对炉批号与实物标识一致；
3. 贸易商供货的，要求其提供上游生产企业的授权与资质文件；
4. 建立供应商资质台账，到期前预警复核。

## 案例十二：合同实质性内容背离招标文件（招采场景）

### 常见情形
中标后另行签订「补充协议」，变更价格、付款方式、工期等实质性内容；或中标价格与合同价格不一致。

### 风险后果
违反招标投标法的强制性规定，合同可能被认定无效；国有企业相关责任人面临审计与纪律追责。

### 依据
《招标投标法》第四十六条（招标人与中标人应按招标文件和中标人的投标文件订立书面合同，不得再行订立背离合同实质性内容的其他协议）；《招标投标法实施条例》。

### 审查要点
1. 比对合同条款与招标文件、投标文件、中标通知书的一致性（价格、范围、工期、付款、质量标准）；
2. 确需变更的，审查是否履行了法定变更程序，变更内容是否属于实质性内容；
3. 警惕以「补充协议」「备忘录」「会议纪要」形式规避招标结果的行为；
4. 关注合同签订时间是否在中标通知书发出后 30 日内。

## 案例十三：签约主体与授权存在瑕疵

### 常见情形
与分公司签订合同但分公司无总公司授权；由非法定代表人签署且未附授权委托书；公章与合同专用章使用混乱；对方使用未备案的印章。

### 风险后果
合同效力待定或被认定无效；出现纠纷时无法约束真正的责任主体（总公司）。

### 依据
《民法典》第一百七十一条（无权代理）、第五百零四条（越权代表）；《公司法》关于法定代表人权限与对外担保的规定；《九民纪要》关于盖章行为效力的裁判规则。

### 审查要点
1. 核验营业执照、法定代表人身份，签约人非法定代表人时必须要求授权委托书（明确授权范围与期限）；
2. 与分公司签约的，核对其经营范围与总公司授权文件；
3. 关注印章类型与真实性，重要合同建议采用盖章 + 签字双重确认；
4. 涉及担保的，审查是否履行了公司内部决议程序。

## 案例十四：争议解决条款约定不明

### 常见情形
约定「可向仲裁机构申请仲裁或向法院起诉」，或仲裁机构名称写错（如「XX 市仲裁委员会」不存在），或管辖法院约定不明确。

### 风险后果
条款可能被认定无效，最终按法定管辖处理（通常为被告所在地或合同履行地），增加维权成本、丧失主场优势。

### 依据
《民事诉讼法》关于协议管辖的规定；《仲裁法》关于仲裁协议有效的要件（明确的仲裁机构）。

### 审查要点
1. 仲裁与诉讼只能择一，不能并列约定；
2. 选择仲裁的，写明准确的仲裁委员会全称；
3. 选择诉讼的，约定明确的管辖法院（如「采购方所在地人民法院」），并确保与合同履行地、被告住所地有实际联系；
4. 涉外合同单独约定适用法律与争议解决方式。

## 案例十五：发票与含税价条款不明，税率调整引发争议

### 常见情形
合同只写「总价 XX 元」，未写明含税/不含税、发票类型（专票/普票）、税率；税率调整后双方对结算价各执一词。

### 风险后果
采购方可能无法取得可抵扣的增值税专用发票，或需额外承担税差；结算金额争议影响付款进度与成本核算。

### 依据
《发票管理办法》；增值税相关规定；《民法典》合同编关于价款约定的规则。

### 审查要点
1. 明确价款是否含税、发票类型、税率及开票时间；
2. 约定税率调整时的价格调整机制（含税价不变 / 不含税价不变）；
3. 约定先票后款或票款同步，明确未开票的付款抗辩；
4. 约定发票不合规（虚开、项目不符）时的重开义务与违约责任。
